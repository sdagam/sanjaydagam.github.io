Matrix Calculus: Derivatives of Matrices and the Chain Rule

#155 of 156 December 19, 2026 Group 6 · Jul 2026–Jan 2027

Every time you train a neural network — the technology behind ChatGPT, image recognition, and medical diagnosis — the computer calculates billions of derivatives simultaneously. Not the derivative of one function with respect to one variable, but the derivative of one function with respect to millions of variables, all at once. Standard calculus handles one variable at a time. Matrix calculus extends derivatives to entire matrices and vectors simultaneously, turning what would be billions of individual calculations into a handful of compact matrix operations. It's the mathematical engine that makes modern AI computationally feasible.

Why Derivatives of Matrices?

Training a neural network means adjusting millions of weights — numbers in the network — to minimize a loss function (a measure of how wrong the network's predictions are). Gradient descent (the training algorithm) needs to know: for each weight, does increasing it increase or decrease the loss? That's a derivative — the rate of change of the loss with respect to each weight.

With one million weights, computing one million separate derivatives would require one million separate calculations. Matrix calculus packages all those derivatives into a single matrix or vector — the gradient — and computes the whole thing at once using matrix operations that modern computers execute extremely efficiently.

Derivatives with Respect to Vectors

If f is a scalar function of a vector x = (x₁, x₂, ..., xₙ), the derivative of f with respect to x is the gradient vector — a vector of all partial derivatives:

Scalar function of a vector: f: Rⁿ → R (takes n numbers, outputs one number) Gradient: ∂f/∂x = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]ᵀ Each component ∂f/∂xᵢ answers: "if I increase xᵢ by a tiny amount, how much does f change?" The gradient points in the direction of steepest increase of f. Gradient descent moves opposite to the gradient — downhill.

For a vector function of a vector (where both input and output are vectors), the derivative is a matrix — the Jacobian. Entry (i,j) of the Jacobian is ∂fᵢ/∂xⱼ — how the i-th output changes when the j-th input changes. Jacobians are the multivariable chain rule's building block.

The Matrix Chain Rule

In single-variable calculus, if y = f(g(x)), then dy/dx = f'(g(x)) × g'(x). The chain rule multiplies derivatives. For matrix calculus, derivatives become matrices (Jacobians), and the chain rule becomes matrix multiplication:

Chain Rule for vectors: If z = f(y) and y = g(x), then: ∂z/∂x = (∂z/∂y) × (∂y/∂x) = Jacobian of f × Jacobian of g = matrix multiplication For a neural network with layers L₁, L₂, ..., Lₖ: ∂loss/∂x = (∂loss/∂Lₖ)(∂Lₖ/∂Lₖ₋₁)...(∂L₂/∂L₁)(∂L₁/∂x) = product of Jacobian matrices for each layer This is backpropagation — the training algorithm for neural networks. The chain rule, applied to matrix functions, automatically propagates the gradient from the output all the way back to the input weights.

Key Matrix Derivative Identities

Certain matrix derivatives appear repeatedly in machine learning and are worth knowing:

∂(Ax)/∂x = Aᵀ (derivative of linear function Ax) ∂(xᵀAx)/∂x = (A + Aᵀ)x (derivative of quadratic form) ∂(tr(AB))/∂A = Bᵀ (tr = trace, sum of diagonal entries) ∂(log det A)/∂A = (Aᵀ)⁻¹ (derivative of log-determinant) These formulas look like scalar calculus rules but for matrices. The transpose appears in the same role as "reverse" in the scalar chain rule.

Automatic Differentiation

Modern deep learning frameworks (PyTorch, TensorFlow) implement automatic differentiation — the ability to compute derivatives of any computation graph automatically. The user writes the forward calculation (computing the loss from the inputs). The framework automatically applies the matrix chain rule backward through every operation to compute all derivatives simultaneously. This is backpropagation, and it's entirely based on matrix calculus. Without it, training networks with billions of parameters would be computationally impossible.

Conclusion

Matrix calculus extends derivatives from single numbers to vectors and matrices, packaging millions of partial derivatives into compact mathematical objects. The gradient of a scalar function is a vector pointing uphill. The Jacobian of a vector function is a matrix of all partial derivatives.
